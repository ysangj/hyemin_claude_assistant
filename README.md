# Hyemin's Assistant 사용법

이 폴더는 Claude Code로 움직이는 개인 비서예요. 영역별로 에이전트 네 개가 있고, 모두 가장 성능이 좋은 **Fable 모델**로 돌아요.

| 에이전트 | 하는 일 |
|---|---|
| 학교 | 수업 일정, 강의자료 정리, 과제(페이퍼, 슬라이드), 시험 대비 |
| 비자 | H-1B, OPT, CPT, E-2 뉴스와 자격 판단, 졸업 후 체류 경로 |
| 사업 | 미국 법인 설립, 화장품 규제, 시장 조사, 콜드메일, 웹페이지 |
| 취업 | 레쥬메, 커버레터, 채용 공고 수집, 지원 현황 관리 |

## 시작하기
터미널에서 이 폴더로 들어가 `claude`를 실행해요.

```
cd ~/codes/hyemin_claude_assistant
claude
```

## 에이전트와 이야기하는 법
정해진 형식이 없어요. 하고 싶은 말을 그대로 하면 돼요.

- **그냥 말하기:** "오늘 일정 알려줘", "인턴 오퍼 받았는데 CPT 돼?" 하면 맞는 에이전트가 알아서 답해요.
  - 메인 에이전트가 학교, 비자, 사업, 취업 중 어디에 해당하는지 판단해서 연결해요. 답 첫 줄에 `→ 비자 에이전트`처럼 누가 맡았는지 표시돼요.
  - 여러 영역에 걸치면 나눠서 처리해요. 예: 인턴 오퍼는 비자(CPT)와 취업(지원 기록)이 함께 맡아요.
  - 애매할 때만 한 번 짧게 물어봐요.
- **과제·시험은 던져주기만 하면 기억해요:** 과제 설명서나 실라버스를 드래그하거나 "다음 주 화요일 중간고사야"라고 말하면, 어느 에이전트와 이야기하던 중이든 바로 일정에 저장해요. 지우지 않고 계속 기억해요.
- **"나 바빠?"는 아무 에이전트한테나 물어봐도 돼요:** "나 오늘 바빠?", "이번 주 바쁨?", "시험 언제야?" 하면 다가오는 마감과 시험을 D-day와 함께 쫙 보여줘요. `/school`을 붙여도 되고, 커맨드 없이 물어봐도 되고, `/business 나 이번 주 바쁨?`처럼 다른 에이전트에게 물어도 똑같이 답해요. 일정 전용 커맨드는 따로 없어요.
- **커맨드로 지정하기:** 어느 에이전트인지 확실히 하고 싶으면 `/school`, `/visa`, `/business`, `/job` 뒤에 말을 붙여요.
- **파일 주기:** PDF, 워드, PPT 파일을 터미널 창에 끌어다 놓으면 돼요. 실라버스, I-20, LinkedIn PDF 같은 자료를 이렇게 넘겨요.
  - 학교 자료는 Finder에서 `school/inbox/`에 넣어두고 "inbox 정리해"라고 해도 돼요.

에이전트는 이렇게 일해요.
- 결과에 꼭 필요한 정보가 비어 있으면 먼저 물어봐요. 귀찮으면 "알아서 해"라고 하면 돼요.
- 결과를 넘길 때 자체 평가, 더 좋게 만드는 방법, 필요한 정보를 같이 알려줘요.
- 에이전트끼리 정보를 공유해요(`shared/` 폴더). 예를 들어 취업 에이전트는 비자 판단을 비자 에이전트 기준으로 해요.
- 말투나 방식을 고쳐 달라고 하면 그 자리에서 규칙에 적고, 모든 에이전트에 반영해요.

## 유용한 커맨드

| 커맨드 | 예시 |
|---|---|
| `/school` | `/school 이 실라버스대로 일정 저장해` (파일 드래그) |
| | `/school 과제 설명서 보고 3페이지 리포트 써줘` |
| | `/school 나 이번 주 바빠?` (일정은 커맨드 없이 "나 오늘 바빠?"라고만 해도 돼요) |
| `/visa` | `/visa 오늘까지 뉴스로 내 상황 정리해줘` |
| `/visa-daily` | 비자 뉴스 점검을 지금 한 번 돌려요. "점검 해줘"라고 하면 매일 자동 점검을 걸고, 결과를 메일로 받을 수 있어요 |
| `/business` | `/business LLC랑 C-corp 중에 뭐가 나아?` |
| | `/business 뉴욕 K-뷰티 바이어 찾아서 메일 써줘` |
| `/job` | `/job 이거 내 링크드인 PDF야, 레쥬메 만들어줘` |
| | `/job 뉴욕 마케팅 포지션 다 가져와 봐` |

Claude Code 기본 커맨드 중 알아두면 좋은 것:
- `/mcp`: Gmail 같은 외부 연결 상태를 확인하고 다시 연결해요.
- `/clear`: 대화를 새로 시작해요. 저장된 파일과 규칙은 그대로 남아요.

## 이메일 보내기 설정
메일(콜드메일, 지원 메일, 비자 점검 리포트)은 Gmail로 보내요. 처음 한 번만 설정하면 돼요.

1. Claude Code에서 `/mcp`를 입력하고 **claude.ai Gmail**을 선택해 연결해요.
2. Google 동의 화면이 뜨면 **Gmail 권한 체크박스를 전부 체크**하고 허용해요. 하나라도 빠지면 메일을 못 보내요.
3. 연결한 뒤 "Gmail 연결 확인해줘"라고 하면 에이전트가 제대로 연결됐는지 확인해요.

**"Insufficient scope"(권한 부족) 오류가 날 때**
`/mcp`에서 다시 연결해도 예전 권한이 그대로 남아 있어서 해결되지 않아요.
1. https://myaccount.google.com/permissions 에서 Claude 접근 권한을 삭제해요.
2. claude.ai 웹의 **설정 → 커넥터 → Gmail**에서 연결을 끊고 다시 연결해요. 이때 체크박스를 전부 체크해요.
3. Claude Code에서 `/mcp`를 한 번 실행해요.

**발송 규칙**
- 보여주기 전에 메일 검토 에이전트(Fable)가 초안을 먼저 검토해요.
  - 지어낸 내용이 없는지 확인해요.
  - 받는 사람의 이름, 직함, 회사 같은 정보가 맞는지 확인해요.
  - AI가 쓴 티가 나는지 확인해요.
- 검토를 거쳐 고친 초안 전체를 검토 결과와 함께 보여줘요. 받는 사람, 제목, 본문, 첨부가 모두 들어 있어요.
- **"보내"라고 해야만 보내요.** "괜찮네" 정도로는 보내지 않고 다시 물어봐요.
- 승인한 뒤에 한 글자라도 바뀌면 다시 승인을 받아요.
- 예외는 하나예요. "점검 해줘"로 걸어둔 비자 일일 리포트는 정해둔 주소로 매번 묻지 않고 보내요.

## 최신 버전으로 업데이트하기
개발자가 에이전트를 고치면 GitHub에 새 버전이 올라와요. 받으려면 Claude에게 이렇게만 말하면 돼요.

> "최신 버전으로 업데이트 해줘" 또는 "깃 풀 해줘"

- Claude가 `update.sh`를 돌려요. 내가 쌓은 기록(활동 기록, 일정, 프로필, 과제, 리포트)은 잠시 치워 뒀다가 업데이트 후 그대로 되돌려요.
- 같은 파일이 양쪽에서 바뀌었으면 Claude가 두 내용을 합쳐요. 내 기록은 지우지 않아요.
- 업데이트 전 내 파일은 항상 `.local-backup/` 폴더에 복사본이 남아요. 문제가 생기면 여기서 되살릴 수 있어요.
- 터미널에서 직접 하려면 `./update.sh`를 실행해요. 다만 충돌 합치기는 Claude에게 맡기는 게 편해요.

## 폴더 구조
```
school/     학교 (schedule.md = 일정, courses/ = 과목별 자료와 과제)
visa/       비자 (profile.md = 내 신분 정보, rules.md = 현재 규칙)
business/   사업 (profile.md, outreach.md = 연락 대상과 메일 기록)
job/        취업 (profile.md, tracker.md = 지원 현황)
shared/     에이전트 공용 (user.md = 내 기본 정보, activity.md = 활동 기록)
update.sh   최신 버전 받기 (내 기록은 지키면서)
.local-backup/  업데이트 전 내 파일 복사본 (GitHub에 안 올라감)
```
각 폴더의 `profile.md`와 `shared/user.md`를 채워두면 에이전트가 덜 물어보고 더 정확하게 일해요.
