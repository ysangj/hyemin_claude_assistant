# 학교 일정

> 학교 날짜의 유일한 원본이다. 어느 에이전트든 과제·시험 날짜를 받으면 여기에 바로 적는다(CLAUDE.md "학교 일정 기억").
> 사람이 직접 고쳐도 된다. **지우지 않는다.** 지난 일정은 상태만 바꾸고, 날짜가 바뀌면 옛 날짜를 남긴다.
>
> 줄 형식: `- MM/DD (요일) HH:MM · 과목 · 종류 · 이름 (비중) · 상태 · [brief](경로)`
> - 종류: 마감 / 시험 / 퀴즈 / 발표 / 수업 / 기타
> - 상태: 시작 전 / 진행 중 / ✅ 제출 / ✅ 응시 / 지남
> - 예: `- 10/14 (수) 23:59 · ACC 601 · 마감 · HW 3 (5%) · 시작 전 · [brief](courses/acc601/hw3/brief.md)`
